# Mavaya, page de présentation

Page de présentation de Mavaya, plateforme qui aide les parents solos à faire le point sur leur situation et à trouver les aides adaptées. Projet portfolio Holberton School de Hugo Lacassagne et Pierre Rouvellat (septembre à novembre 2026).

Le code de la plateforme est dans un dépôt privé : le cahier des charges de l'association est confidentiel. Ce dépôt ne contient que la page de présentation.

## Contenu

- `index.html` : la page (introduction, principes, trois fonctionnalités, vidéo de démonstration, à propos avec les chiffres de l'INSEE, équipe), avec un mode clair et un mode sombre
- `style.css` : le style, aux couleurs et polices de la charte Mavaya
- `images/` : logo, photos et captures d'écran de la plateforme

Les photos sont sous licence Adobe Stock, acquise par l'association pour un usage web.

## Publication

GitHub Pages, depuis la branche `main`, dossier racine : Settings, puis Pages, puis « Deploy from a branch ».
